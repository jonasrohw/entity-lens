\section{The contrastive Jacobian lens}
\label{sec:lens}
\citet{gurnee2026workspace}'s Jacobian lens is broadly
similar to LRE.  But
instead of a relation-specific prompt and a focused target
position (the object),
it computes the average 
$W = \operatorname{mean}_i J_i$ over many diverse prompts and many
output positions. The Jacobian lens also does not use the
``anchor'', the zero-order term of the Taylor expansion; so it
is simply $W = \operatorname{mean}_i J_i$.

We derive our \emph{contrastive Jacobian lens} from
Eq.~\ref{eq:beta}, restated as:
\begin{equation}
  f(s) \approx
\beta W s + b_\beta \;=\;
\operatorname{mean}_i\!\left[\,f(s_i)\right]
+ \beta\operatorname{mean}_i\!\left[\, J_i (s - s_i)\,\right]
\end{equation}
Following \citet{gurnee2026workspace}, we also drop the anchor
term $\operatorname{mean}_i\!\left[\,f(s_i)\right]$; see discussion in 
\S\ref{sec:swap}.
This also means that we do not need $\beta$ since the
scaling does not change the output distribution over
tokens. The final form of the contrastive Jacobian lens is then:
\begin{equation}
\mbox{CJL}(s) = \operatorname{mean}_i\!\left[\, J_i (s - s_i)\,\right]
\label{eq:cjl}
\end{equation}
Note that CJL takes into account the difference between $s$ and
the reference point $s_i$ -- as it should  if we want
to approximate $f(s)$ using the first derivative. This
difference formalization is
also the main motivation for introducing our alternative
lens. We are not interested in what the model associates
with an entity like ``Russia'' in general (e.g.,
``Europe''). Instead we are interested in what the model
associates with ``Russia'', but not with other reference
entities like ``Spain'' and ``Italy''. Examples of such
contrastive associations or ``Russia'' are ``vodka'' and ``Kremlin''.
The basic idea we will investigate is that such top-ranked contrastive associations
give rise to linearity.

To instantiate the contrastive Jacobian lens for factual
relations, we need (i) a prompt that evokes factual associations
and (ii) a reference set that contrasts an entity with entities
of the same type. 

As the prompt we adopt 
\texttt{"\{\} is known for"}. This a neutral prompt, i.e.,
it is not customized for any specific factual relations. We
use it for all our  experiments unless otherwise stated.

As the reference set, we use entities of the same type as
the subject, e.g., other countries if the subject is a
country, other landmarks if the subject is a landmark
etc.
The non-contrastive
standard Jacobian lens applied to an input $s$ outputs anything the model is likely
to say in a context in which $s$ occurs, including features
it shares with other same-type entities.
The contrastive
Jacobian lens is trained to output only what differentiates
$s$ from other same-type type.

\paragraph{Computation.} We do not compute $J_i$ explicitly, but obtain each
Jacobian--vector product $J_i u$ by the double-backward
construction \citep{pearlmutter1994fast}, at the cost of a constant
number of forward and backward passes; this is what makes
Eq.~\ref{eq:lens} affordable at $d_{\text{model}}=4096$
(Appendix~\ref{sec:jvp}).

\paragraph{The relation score.} We decode $\mbox{CJP}(s)$ over the full vocabulary
and record the rank of $m_e$, the model's own top-1 answer for relation
$r$, obtained under the relation's in-context prompt (\S\ref{sec:setup}).
Writing $\mathrm{rk}_{\mbox{CJL}(e)}(m_e)$ for that rank, the diagnostic for a
relation is
\begin{equation}
A_r \;=\; -\operatorname{median}_{e}\,\log_{10}\mathrm{rk}_{\mbox{CJL}(e)}(m_e),
\end{equation}
so higher $A_r$ means the lens agrees with the model more.

\paragraph{What makes $A_r$ relation-agnostic.} Nothing on the lens side
of Eq.~\ref{eq:lens} is specific to $r$: the prompt is neutral and shared,
the layer is fixed at 17 for all relations
(Appendix~\ref{sec:layer17}), and the differences are
subject-minus-subject -- \emph{France} minus \emph{Spain}, never
\emph{France} minus \emph{Paris} -- so no (subject,~object) pair of the
relation is used in estimation. Relation-specificity enters in exactly
one place, the \emph{target} $m_e$, the quantity
faithfulness is defined against.
